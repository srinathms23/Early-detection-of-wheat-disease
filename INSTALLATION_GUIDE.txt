INSTALLATION STEPS
═════════════════════════════════════════════════════════════════════════════

1. INSTALL PYTHON
   - Download from python.org
   - Add Python to PATH
   - Verify: python --version (should be 3.8+)

2. EXTRACT PROJECT
   - Extract wheat_disease_detection folder to your location

3. OPEN TERMINAL/CMD
   - Navigate to project folder
   - cd wheat_disease_detection

4. CREATE VIRTUAL ENVIRONMENT (Optional but Recommended)
   - python -m venv venv
   - venv\Scripts\activate (Windows)
   - source venv/bin/activate (Mac/Linux)

5. INSTALL DEPENDENCIES
   - pip install -r requirements.txt
   - This takes 5-10 minutes first time

6. VERIFY INSTALLATION
   - python -c "import tensorflow as tf; print(f'TensorFlow {tf.__version__}')"

═════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: "Module not found error"
Solution: pip install -r requirements.txt

Problem: "Model not found"
Solution: python train.py --create-dataset

Problem: "Out of memory"
Solution: python train.py --batch-size 8 --epochs 20

Problem: "Port already in use (Flask)"
Solution: python app.py --port 8000

Problem: "TensorFlow installation fails"
Solution: pip install --upgrade tensorflow
